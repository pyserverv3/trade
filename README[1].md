# Lutan Trading Academy

GitHub Pages-ready static website.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. Go to Settings -> Pages.
4. Choose `Deploy from a branch`.
5. Select `main` and `/root`.
6. Save.

Replace the placeholder links, text, photos and contact/community URL with your own content.

This template is an original implementation inspired by a modern trading-academy landing-page structure. It does not include the reference site's proprietary code, images, testimonials or branding.
